# Page Moved

Provider configuration examples have moved to the top-level `Coding Agent` topic.

The reason for the move is not a directory reshuffle, but rather that the real implementation of these capabilities lives in `ai4j-cli` / `ai4j-coding`:

- provider/profile resolution chain
- workspace binding
- session runtime re-binding
- CLI `/provider` / `/model` commands

Therefore this old page only keeps a compatibility entry point and no longer maintains a second copy of the content.

Please use the new official documentation:

1. [Configuration System](/docs/coding-agent/configuration)
2. [Provider Profile and Model Switching](/docs/coding-agent/provider-profiles)
3. [Command Reference](/docs/coding-agent/command-reference)
